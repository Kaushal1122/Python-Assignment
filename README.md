# Python Assignment

This repository contains Python practice programs developed with an emphasis on clean code, maintainability, and software engineering best practices.

## Requirements

The programs aim to follow:

- PEP 8 coding standards
- Appropriate software design principles
- Python logging standards
- Exception handling
- Configuration management
- Unit testing

## Programs

1. MySQL Database Processing Using Generators
2. Abstract Classes and Inheritance
3. Removing Duplicates While Preserving Order
4. Using `map()` and `lambda` to Calculate Squares
5. Removing HTML Tags from Web Content

## Technologies

- Python
- MySQL
- pytest
- Git and GitHub

Each program will include its implementation, relevant tests, and instructions for execution.
